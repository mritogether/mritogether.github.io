# Resources

The 2026 edition of MRI Together is a hackathon that builds an open-source, end-to-end pipeline for placenta diffusion MRI, from the sequence to the analysis, using community-trusted tools.

## Environment

Every hands-on session runs in one environment on your own computer: JupyterLab with Python and Julia kernels and a bash shell, holding all the tools below. Set it up before 23 November from the setup repository **[here](https://mcencini.github.io/mritogetherthon)**.

## Packages

- [PyPulseq](https://github.com/imr-framework/pypulseq): open-source MRI sequence design in Python.
- [KomaMRI](https://github.com/JuliaHealth/KomaMRI.jl): Bloch simulation of MRI sequences in Julia.
- [BART](https://mrirecon.github.io/bart/): Berkeley toolbox for MRI reconstruction.
- [SigPy](https://github.com/mikgroup/sigpy): signal processing and iterative reconstruction in Python.
- [PyTorch](https://pytorch.org/): deep learning framework (CPU build).
- [DIPY](https://dipy.org/): diffusion MRI analysis.
- [scikit-image](https://scikit-image.org/): image processing algorithms.
- [NiBabel](https://nipy.org/nibabel/): reading and writing neuroimaging file formats.
- [ISMRMRD](https://ismrmrd.github.io/): raw MRI data format.
- [h5py](https://www.h5py.org/): HDF5 files from Python.
- [pydicom](https://pydicom.github.io/): reading and writing DICOM files.
